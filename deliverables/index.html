Culinary Expansion

カリナリー・エクスパンション

MOD内容紹介

Minecraftの食卓に、もっと料理を。
料理系のアイテムとレシピを追加するForge MOD・PaperMCプラグインです。

目玉焼きやハンバーガー、ジュースなどの料理とレシピを追加します。材料を組み合わせたり、かまどや燻製器で調理したりして作れます。

料理図鑑では、料理の画像、回復量、効果、材料、クラフト配置を確認できます。

導入方法
  1. Java 25を使用するMinecraft 26.3環境を用意します。
  2. Forge 66.0.5をインストールします。
  3. JARをゲームフォルダーのmodsに入れます。
  4. Forgeのプロファイルでゲームを起動します。

マルチプレイでは、参加者とサーバーに同じバージョンのMODを導入してください。
