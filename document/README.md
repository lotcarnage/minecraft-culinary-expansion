# 開発用文書

このディレクトリにはMODの設計、料理追加の仕様、開発メモなどを配置します。

- 開発環境・ビルド・動作確認・公開の手順は[ルートのREADME](../README.md)を参照してください。
- GitHub Pages向けのHTML・画像・配布JARは`deliverables/`に配置します。
- Pagesの公開元は`main`ブランチのルートです。公開ページのURLは`https://lotcarnage.github.io/minecraft-culinary-expansion/deliverables/`です。

## 追加アイテムのダッシュボード

[追加アイテム一覧](item_dashboard.html)をブラウザーで開くと、アイテムごとの属性とレシピを確認できます。

リポジトリのルートで次のコマンドを実行して、実装変更後に再生成してください。Pythonの標準ライブラリだけで動作し、MODのビルドは不要です。

```sh
python helper/generate_item_dashboard.py
```

出力先は`document/item_dashboard.html`です。`--output <HTMLファイル>`で変更できます。画像はHTMLに埋め込むため、単体でオフライン表示できます。編集対象ファイルへのリンクはリポジトリ内の相対パスです。

各列は単一属性です。アイテム表では日本語名、英語名、スタック数、使用動作、満腹度回復量、隠し満腹度係数、隠し満腹度最大回復量、満腹時使用などを独立した列で比較できます。レシピ・材料・テクスチャ・確認事項は連番付きの独立した列に展開し、全情報を1アイテム1行の同じ表に表示します。複数値を一つのセルに詰め込みません。アイテムID列とヘッダーを固定し、横スクロールで属性を比較できます。

このスクリプトはJavaを実行するものではなく、文字列のMOD_ID・ITEMS.registerと直接指定された属性を解析します。独自アイテムクラス、変数・メソッド経由の属性、複合モデル、独自レシピ形式の完全な解析には対応しません。「要確認」の項目は編集対象のソースを確認してください。
調理列は、かまど対応・燻製器対応・焚き火（対応時はtick数、非対応は不可）・基準調理時間（tick）・調理経験値に整理しています。同じアイテムのレシピで材料・出力個数・経験値が異なる場合や、同じ調理方法に複数レシピがある場合は、情報を省略せず生成エラーとして通知します。

## リソース管理一覧

[リソース管理一覧](resource_dashboard.html)に、モデルID・Javaソース・表示定義・レシピIDとファイル・テクスチャIDとファイル名・画像寸法・確認事項をまとめています。アイテム比較一覧にはゲーム内の属性、調理方法、材料、画像を表示します。`python helper/generate_item_dashboard.py`で両方を同時生成します。`--output`で出力先を指定した場合、管理一覧は同じディレクトリの`resource_dashboard.html`に生成されます。

クラフト方式は「クラフト不可・定型・不定形」です。素材欄は行:列の順で1:1、1:2、1:3、2:1、2:2、2:3、3:1、3:2、3:3の9列です。定型はレシピの配置を左上に揃え、不定形は材料を順に並べます（実際の配置順序は任意）。空きマスは「不要」、クラフト不可の素材欄は「不可」です。1マスから1個消費するため、素材ごとの必要数列は設けません。タグ素材は#で識別します。複数レシピは連番付きの列に展開します。

- [GUIアイテムエディター](item_editor.md): `python helper/item_editor.py`で起動。1つのJSONからアイテム定義とレシピを生成します。
